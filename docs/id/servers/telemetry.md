# Telemetri & Monitoring Real-Time

Pantau beban CPU, RAM, disk, dan riwayat utilisasi seluruh server Anda secara *real-time* tanpa perlu menginstal Prometheus node-exporter atau Telegraf.

---

## Metrik yang Dipantau

- **CPU & Load Average**: Persentase pemakaian CPU real-time dan load average (1m, 5m, 15m).
- **RAM & Swap**: Total, terpakai, free, cache, dan pemakaian memori swap.
- **Penyimpanan Disk**: Kapasitas partisi root dan storage volume tambahan.
- **Peringatan Discord & Webhook**: Notifikasi otomatis saat CPU > 90% atau disk tersisa di bawah 10%.
