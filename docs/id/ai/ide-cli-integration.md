# Integrasi IDE & CLI

Hubungkan perkakas coding AI favorit Anda ke AI Gateway lokal 7Server.

---

## Claude Code CLI

```bash
# Tambahkan ke ~/.zshrc atau ~/.bashrc:
export ANTHROPIC_BASE_URL="http://localhost:5001"
export ANTHROPIC_API_KEY="7s-sk-live-kunci-virtual-anda"

# Jalankan Claude Code
claude
```

7Server meneruskan permintaan ke akun Claude yang terhubung dengan dukungan penuh untuk prompt caching dan streaming.
