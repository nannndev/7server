# Universal AI Gateway

Gateway internal yang kompatibel dengan protokol OpenAI (`/v1/chat/completions`) dan Anthropic (`/v1/messages`).

---

## Hubungkan Akun Langganan

Masuk menggunakan akun langganan resmi Anda tanpa harus membeli saldo API terpisah:
- **Claude Pro / Team** (OAuth PKCE)
- **ChatGPT Plus / Team** (OAuth)
- **GitHub Copilot** (Device Code Flow)
- **Google Gemini**

Seluruh token akses disimpan terenkripsi di database lokal 7Server.
