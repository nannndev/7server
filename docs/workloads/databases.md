Interact directly with your server databases—including database engines running inside Docker containers or natively on the host.

## Supported Engines

- **PostgreSQL**: Query editor, table inspector, schema diagrams, and index performance.
- **MySQL / MariaDB**: Database browser, table records view, and SQL console.
- **MongoDB**: Collection browser, document viewer, and JSON query runner.
- **Redis**: Key-value inspector, TTL watcher, memory statistics, and Redis CLI.
- **SQLite**: Local file inspection, schema analyzer, and lightweight queries.

---

## Interactive ER Diagrams

7Server can automatically generate interactive Entity-Relationship (ER) visual diagrams from your database schemas, displaying foreign keys, primary keys, and relational cardinality.
